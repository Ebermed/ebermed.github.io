# Webfolio de Ebermed

Sitio estático listo para GitHub Pages.

## Publicarlo

1. Crea un repositorio público en GitHub.
2. Sube `index.html`, `styles.css` y `.nojekyll` a la raíz del repositorio.
3. En **Settings → Pages**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/root`.
4. Guarda y abre la dirección que GitHub genere.

El enlace del canal aparece como `https://www.youtube.com/@ebermed`; si el identificador público del canal es distinto, reemplázalo en `index.html`.
